## ✨ Overview

Planet Facts Site is a web project focused on making information about our Solar System accessible through a simple and interactive interface.

Browse all eight planets and explore information about their composition, internal structure, geology, and physical characteristics.

Each planet has its own dedicated page, with organized information and useful reference links.

## 🚀 Features

- **Eight Planet Pages** — Explore Mercury, Venus, Earth, Mars, Jupiter, Saturn, Uranus, and Neptune.
- **Three Information Sections** — Switch between Overview, Structure, and Geology.
- **Planet Statistics** — Discover rotation period, revolution period, radius, and average temperature.
- **Responsive Navigation** — Navigate between planets on desktop and mobile.
- **Dynamic Content** — Planet information is rendered from structured JSON data.
- **Source References** — Each information section includes a link to its source.
- **Client-Side Routing** — Each planet has its own URL.

## 💻 Getting Started

Want to run the project locally?

### Prerequisites

- Node.js
- npm

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/LEVANIKAPANADZE/Planets-Fact-Site.git
   ```

2. Navigate into the project directory:

   ```bash
   cd Planets-Fact-Site
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL shown in your terminal.

## 📦 Available Scripts
